## 获取 API Key 

API Key 是用于验证接口请求身份的唯一密钥凭证。

请前往“[API 控制台](https://ati.threatbook.cn/apiconsole)”页面进行操作。

该 API Key 会根据您的订阅方案自动具备所有对应 API 接口的调用权限。


## 绑定访问 IP (Access IP)

在发起 API 请求之前，请确保已将发起请求的服务器 IP 地址绑定至 API Key 白名单，并确认账户具备目标 API 的授权额度。您可以在[API 控制台](https://ati.threatbook.cn/apiconsole)完成该绑定操作
