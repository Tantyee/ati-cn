# 威胁情报类型(`threat_types`/‘intel_types')

## 威胁类型分类

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **C2** | 攻击者搭建的远控命令与控制 (C&C) 服务器，用于向失陷主机下发指令并接收窃取的敏数据。存在活跃连接通常表明主机已失陷。 | 恶意 |
| **Botnet** | 僵尸网络节点，即由被恶意软件感染并远程控制的计算机网络，用于执行协调一致的恶意活动。 | 恶意 |
| **Hijacked** | 遭到劫持的网络地址，攻击者通过劫持通信来冒充可信实体。 | 恶意 |
| **Phishing** | 仿冒合规网站的钓鱼站点，旨在诱骗用户泄露个人敏感信息、账号凭据或财务数据。 | 恶意 |
| **Malware** | 恶意软件分发站点。主机主动连接该地址通常意味着已遭遇恶意软件感染。 | 恶意 |
| **Exploit** | 尝试利用系统漏洞下发恶意脚本或 Payload，以获取未授权访问或执行任意任务。 | 恶意 |
| **Scanner** | 发起网络扫描活动以识别漏洞系统、探测 Exploit 或收集网络情报，通常由 Bot、蠕虫或攻击者发起。 | 恶意 |
| **Zombie** | 已失陷充当 Bot 的傀儡主机，被远程控制以发起网络攻击、传播恶意软件或窃取数据。 | 恶意 |
| **Spam** | 关联大批量发送垃圾邮件/恶意内容，通常使用自动化 Bot 或邮箱抓取系统。 | 恶意 |
| **Compromised** | 属于已被攻击者渗透并控制的主机，可能被用于发起网络攻击、分发木马、窃密或充当 Bot。 | 可疑 |
| **Brute Force** | 发起暴力破解攻击，通常使用自动化工具穷举密码或凭据以试图获取未授权访问。 | 恶意 |
| **Suspicious** | 包含不良或非法内容的可疑站点，虽未直接参与远程控制用户，但存在风险。 | 可疑 |
| **Trusted** | 属于可信的网络服务节点。 | 安全 |

## “C2” 子类型

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **Sinkhole C2** | 原 C2 远控服务器，现已被安全机构接管。来自失陷主机的流量被重定向至此，用于收集情报与辅助处置。 | 恶意 |

## “可疑” 子类型：挖矿相关

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **CoinMiner** | 攻击者搭建的私有矿池服务，用于接收被感染暗挖木马主机提交的哈希数据。暗挖与资源耗尽的关键指标。 | 恶意 |
| **MiningPool** | 连接矿工与矿池的公共矿池服务器。常被攻击者滥用于未经授权的暗挖，未经批准的流量需重点排查。 | 恶意 |

## “可疑” 子类型：其他

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **Suspicious Application** | 潜在有害的应用或站点，关联恶意软件、钓鱼、欺诈内容、未经授权的数据抓取或恶意广告。 | 可疑 |
| **Suspicious Website** | 可能托管恶意软件的潜在有害网站。 | 可疑 |
| **Reverse Proxy** | 反向代理服务器。有可能被攻击者滥用于内网穿透或绕过网络安全边界。 | 可疑 |
| **C2 Panel** | 关联远控命令与控制 (C2) 的 Web 控制台，允许攻击者远程管理失陷系统、执行命令与外泄数据。 | 可疑 |
| **Fake Software Downloader** | 托管仿冒软件站点的网络地址，模仿正规平台诱骗用户下载恶意软件。 | 可疑 |

## “Phishing” 钓鱼子类型

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **Fake Website** | 仿冒高信誉品牌的欺诈网站（复制品牌、设计与域名），诱骗用户提交敏感凭据或财务细节。 | 恶意 |

## “Brute Force” 暴破子类型

| **类型** | **说明** | **研判结论** |
| :--- | :--- | :--- |
| **SSH Brute Force** | 针对 SSH 服务发起的暴力破解攻击。 | 恶意 |
| **FTP Brute Force** | 针对 FTP 服务发起的暴力破解攻击。 | 恶意 |
| **SMTP Brute Force** | 针对 SMTP 服务发起的暴力破解攻击。 | 恶意 |
| **Http Brute Force** | 针对 HTTP 协议基础认证 (Basic Authentication) 发起的暴力破解攻击。 | 恶意 |
| **Web Login Brute Force** | 针对 Web 登录入口发起的暴力破解攻击。 | 恶意 |

## 网络基础信息

| **类型** | **说明** |
| :--- | :--- |
| **Proxy** | 用于转发网络流量的中继代理服务器。常被攻击者滥用以隐匿真实身份与地理位置。 |
| **HTTP Proxy** | 提供 HTTP 代理服务。 |
| **HTTP Proxy In** | 提供 HTTP 代理服务的入站网关。 |
| **HTTP Proxy Out** | 提供 HTTP 代理服务的出站网关。 |
| **Socks Proxy** | 提供 Socks 代理服务。 |
| **Socks Proxy In** | 提供 Socks 代理服务的入站网关。 |
| **Socks Proxy Out** | 提供 Socks 代理服务的出站网关。 |
| **VPN** | 提供虚拟专用网络 (VPN) 服务，加密路由流量以隐藏真实 IP。常被攻击者滥用以掩盖源头。 |
| **VPN In** | 提供 VPN 服务的入站网关。 |
| **VPN Out** | 提供 VPN 服务的出站网关。 |
| **Tor** | 运行 Tor 匿名通信服务的节点。因高度匿名性，常被攻击者用于托管恶意服务或隐蔽流量。 |
| **Tor Proxy In** | Tor 网络的入站入口节点 (Guard/Bridge)。 |
| **Tor Proxy Out** | Tor 网络的出站出口节点 (Exit)。 |
| **Bogon** | 未分配给公网使用的保留 IP 地址（如私有网络、环回、广播）。极少作为有效的公网威胁指标。 |
| **FullBogon** | 既未分配给任何组织，也未被 IANA 注册在私有地址空间内的未分配 IP 地址。 |
| **Gateway** | 协助局网与公网之间进行数据交换与路由的网关设备。 |
| **IDC** | 属于互联网数据中心 (IDC)。由于 IDC 服务器极少直接发起主动出站请求，其发起的异常流量需重点监控（可能被租用或入侵）。 |
| **Dynamic IP** | 运营商通过 DHCP 动态分配给用户的临时可变 IP 地址。 |
| **Edu** | 源自教育网或学术研究机构的网络。 |
| **DDNS** | 关联动态域名解析服务 (DDNS)。常被攻击者滥用将动态 IP 映射至固定域名以维持 C2 基础设施韧性。 |
| **Mobile** | 移动通信网络（GSM、CDMA、LTE 等）中的基站或收发节点。 |
| **CDN** | 属于内容分发网络 (CDN)。攻击者有时通过域前置 (Domain Fronting) 等技术滥用 CDN 基础设施绕过检测。 |
| **DNS** | 将可读域名解析为 IP 地址的域名解析服务器。 |
| **BTtracker** | 用于 P2P 文件共享的 BitTorrent Tracker 服务器。P2P 网络有时会被滥用于分发恶意软件。 |
| **Backbone** | 运营商高容量骨干网节点的一部分。 |
| **ICP** | 已在 Mainland China 完成 ICP 备案登记的合法网站。 |
| **NRD3M** | 最近 3 个月内新注册的域名 (Newly Registered Domain)。 |
| **IoT Device** | 属于物联网 (IoT) 智能设备。 |
| **Game Server** | 属于网络在线游戏服务器。 |
| **Search Engine Crawler** | 搜索引擎蜘蛛或爬虫。通常不构成网络安全威胁，但大流量访问可能影响服务器稳定性。 |
| **Advertisement** | 属于在线广告服务节点。 |
| **CloudWAF** | 云端 Web 应用防火墙 (WAF) 服务。网站流量在到达源站之前会经过云 WAF 过滤检查。 |
| **AI Gateway Service** | 位于用户应用与人工智能模型服务商之间的中间服务，为大语言模型及其他生成式 AI 模型提供统一 API 接入。此类服务可将多个上游模型或账户整合为统一的 API 接口，供应用程序、开发工具及 AI Agent 调用。 |
| **Remote Management Tool**  | 远程管理工具节点是用于支撑远程控制和远程运维业务的网络基础设施，主要承担客户端连接协调、设备在线状态维护、会话建立及加密流量路由等功能。此类节点通常属于商业远控软件的全球服务网络，相关 IP 可能动态变化。 |
